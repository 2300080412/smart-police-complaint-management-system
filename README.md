# 🚔 Smart Police Complaint Management & Emergency Response System

A modern Django-based web application that enables citizens to report police complaints online with GPS location, evidence image upload, Google Maps integration, complaint tracking, and an admin dashboard for efficient complaint management.

---

## ✨ Features

- 📝 Register police complaints
- 📍 Automatic GPS location capture
- 🖼️ Upload evidence images
- 🗺️ Google Maps integration
- 🔍 Track complaint status using Complaint ID
- 👮 Admin dashboard for complaint management
- 📊 Complaint status updates
- 🚨 Emergency contact page
- 📱 Responsive modern UI
